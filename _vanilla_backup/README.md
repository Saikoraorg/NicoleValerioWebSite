# 📸 Nicole Valerio | Fotografía Profesional & Full Stack Studio

Sitio web interactivo de fotografía profesional de alta gama con enfoque híbrido (fotografía artística + entrega digital desarrollada con tecnologías web modernas).

## 🌟 Características Principales
- **Hero Cinemático:** Foto del fotógrafo/a en primer plano con insignias *glassmorphism* flotantes y fondo animado donde se suceden fotografías con transiciones suaves.
- **Carrusel de Fotos Pequeñas:** Carrusel táctil y deslizable con filtros por categoría (*Retratos, Parejas, Familia, Bodas, Marca, Eventos*), barra de progreso y contador en tiempo real.
- **Visor Lightbox:** Apertura a pantalla completa con ficha técnica de disparo (Cámara, Lente, ISO) y botón para cotizar.
- **Servicios Interactivos:** 6 tarjetas de paquetes con preselección automática al abrir el formulario de cotización.
- **Formulario y Cotizador Modal:** Reserva directa con validación interactiva y campos completos.
- **Portal Digital Privado:** Muestra del valor agregado tecnológico como desarrollador full stack.

## 🚀 Inicio Rápido
Abre `index.html` directamente en tu navegador o ejecuta en tu terminal:
```bash
python -m http.server 8080
```
