# 📸 Nicole Valerio | Fotografía Profesional & Full Stack Studio (Next.js)

Sitio web interactivo desarrollado con **Next.js (App Router) + TypeScript + CSS Modules**, diseñado para promover un estudio fotográfico de alta gama con enfoque tecnológico e interactivo.

## 🚀 Cómo ejecutar en desarrollo

```bash
npm install
npm run dev
```
Abre tu navegador en [http://localhost:3000](http://localhost:3000).

## 🛠️ Comandos disponibles

- `npm run dev` — Inicia el servidor de desarrollo local
- `npm run build` — Compila y optimiza el proyecto para producción
- `npm run start` — Inicia el servidor en modo producción
