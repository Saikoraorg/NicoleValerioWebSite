Estructura de Base de Datos para Supabase

Esquema SQL completo y listo para montar con PostgreSQL, Row Level Security (RLS) y Storage.

1. TABLA: books

Guarda los 11 books con título, slug, número de book, badge, portada y total de fotos sincronizado.

2. TABLA: photos

Almacena cada foto individual con URLs en alta resolución, miniatura, dimensiones y flag de portada.

3. TABLA: bookings

Registra citas del formulario web: cliente, teléfono, email, fecha, hora, tipo de book y estado.

4. TABLA: reviews

Testimonios y calificaciones de 1 a 5 estrellas con moderación de comentarios.

supabase_schema.sql (PostgreSQL Script Oficial) 5 Tablas + RLS + Triggers + Storage Buckets 
-- ==============================================================================
-- STUDIO NVF - NICOLE VALERIO FOTOGRAFÍA EDITORIAL
-- Arquitectura de Base de Datos para Supabase (PostgreSQL + RLS + Storage)
-- ==============================================================================

-- 1. EXTENSIONES
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- 2. FUNCIÓN DE TRIGGER PARA ACTUALIZAR updated_at
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- 3. TABLA: books (Catálogo de Colecciones)
CREATE TABLE IF NOT EXISTS public.books (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    slug TEXT UNIQUE NOT NULL,                          -- ej: 'familia', 'boda', 'embarazo'
    badge_number TEXT NOT NULL,                         -- ej: '01', '02', '03'
    title TEXT NOT NULL,                                -- ej: 'Familia', 'Boda de Autor'
    subtitle TEXT,                                      -- ej: 'Momentos Genuinos'
    category TEXT DEFAULT 'EDITORIAL',                  -- ej: 'EDITORIAL', 'RETRATO'
    description TEXT,
    cover_url TEXT NOT NULL,
    photo_count INTEGER DEFAULT 0,
    sort_order INTEGER DEFAULT 0,
    is_published BOOLEAN DEFAULT true,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 4. TABLA: photos (Galería en Alta Resolución)
CREATE TABLE IF NOT EXISTS public.photos (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    book_id UUID NOT NULL REFERENCES public.books(id) ON DELETE CASCADE,
    name TEXT NOT NULL,
    caption TEXT,
    url_large TEXT NOT NULL,
    url_xlarge TEXT,
    url_thumb TEXT,
    width INTEGER,
    height INTEGER,
    is_cover BOOLEAN DEFAULT false,
    sort_order INTEGER DEFAULT 0,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 5. TABLA: bookings (Citas y Reservas del Calendario)
CREATE TABLE IF NOT EXISTS public.bookings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    client_name TEXT NOT NULL,
    client_email TEXT NOT NULL,
    client_phone TEXT NOT NULL,
    session_type TEXT NOT NULL,                         -- 'Familia', 'Boda', 'Embarazo', etc.
    booking_date DATE NOT NULL,                         -- Fecha (AAAA-MM-DD)
    booking_time TIME NOT NULL DEFAULT '10:30:00',      -- Hora (HH:MM)
    estimated_duration_hours NUMERIC(3,1) DEFAULT 1.5,
    location TEXT,
    message TEXT,
    status TEXT DEFAULT 'Pendiente' CHECK (
        status IN ('Pendiente', 'Confirmada', 'Completada', 'Cancelada')
    ),
    internal_notes TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 6. TABLA: reviews (Calificaciones)
CREATE TABLE IF NOT EXISTS public.reviews (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    author_name TEXT NOT NULL,
    rating INTEGER NOT NULL CHECK (rating >= 1 AND rating <= 5),
    session_type TEXT,
    review_text TEXT NOT NULL,
    is_approved BOOLEAN DEFAULT true,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 7. TABLA: site_assets (Fotos del Hero, Work, Instagram)
CREATE TABLE IF NOT EXISTS public.site_assets (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    section TEXT NOT NULL,
    key_name TEXT NOT NULL,
    title TEXT,
    subtitle TEXT,
    image_url TEXT NOT NULL,
    external_link TEXT,
    sort_order INTEGER DEFAULT 0,
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 8. POLÍTICAS DE SEGURIDAD (RLS)
ALTER TABLE public.books ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.photos ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.bookings ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.reviews ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.site_assets ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Public can view published books" ON public.books FOR SELECT USING (is_published = true);
CREATE POLICY "Admin can manage all books" ON public.books FOR ALL TO authenticated USING (true);

CREATE POLICY "Public can view photos" ON public.photos FOR SELECT USING (true);
CREATE POLICY "Admin can manage all photos" ON public.photos FOR ALL TO authenticated USING (true);

CREATE POLICY "Public can insert bookings" ON public.bookings FOR INSERT TO anon, authenticated WITH CHECK (true);
CREATE POLICY "Admin can manage all bookings" ON public.bookings FOR ALL TO authenticated USING (true);

CREATE POLICY "Public can view approved reviews" ON public.reviews FOR SELECT USING (is_approved = true);
CREATE POLICY "Public can insert reviews" ON public.reviews FOR INSERT TO anon, authenticated WITH CHECK (true);
CREATE POLICY "Admin can manage reviews" ON public.reviews FOR ALL TO authenticated USING (true);

CREATE POLICY "Public can view site assets" ON public.site_assets FOR SELECT USING (true);
CREATE POLICY "Admin can manage site assets" ON public.site_assets FOR ALL TO authenticated USING (true);

🚀 Pasos para Conectar con Supabase

  1. Crea tu proyecto gratuito en supabase.com.
  2. En el menú lateral izquierdo, haz clic en SQL Editor > New Query.
  3. Haz clic en el botón superior "📋 Copiar SQL para Supabase", pégalo en el editor y presiona RUN.
  4. En la pestaña Storage, crea dos buckets públicos: covers y photos.
  5. Copia tu Project URL y anon public key de Project Settings > API para sincronizar la aplicación.
